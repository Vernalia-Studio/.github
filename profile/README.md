Vernalia is a boutique interactive studio. We build the space between a website and an experience. Narrative worlds, ARG campaigns, and digital artifacts for publishing and music clients.

Every project is a **Fossil**: a self-contained, serverless archive designed to outlast the platform it runs on.

---

### PHILOSOPHY

The modern web optimises for frictionlessness. We build **Gates** — interactions that require intention to pass.

Story determines form. We don't impose a format on a brief; we let the brief find its own shape.

---

### WORK

We build for independent publishers, record labels, and artists who want something that can't be templated.

- **ARG campaigns** — layered, discoverable worlds that reward the curious
- **Companion experiences** — narrative extensions that live alongside a book, album, or release
- **Digital exhibitions** — durational web works built to be experienced, not just visited

Commissions: [vernaliastudio.com](https://vernaliastudio.com)

### THE REGISTRY

This organisation is the internal infrastructure layer; the fossil template, build tooling, and studio standards that underpin every project. Most repositories are private. Public releases, when they happen, will be documented here.
